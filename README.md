# 📊 Course 01: Exploratory Data Analysis for Machine Learning

**Status:** 🔄 In Progress  
**Progress Snapshot:** 61% complete as of October 13, 2026  
**Estimated Completion:** October 26, 2026  

**Course Link:**  
https://www.coursera.org/learn/ibm-exploratory-data-analysis-for-machine-learning

### Course Overview

This course introduces the foundations of machine learning with an emphasis on data quality, preparation, exploratory analysis, feature engineering, and statistical inference.

The goal is to understand how to transform raw data into information that can support reliable machine learning models.

### Module 1: A Brief History of Modern AI and its Applications

**Topics:**

- Introduction to artificial intelligence
- Machine learning and deep learning
- History of artificial intelligence
- Evolution of machine learning
- Modern AI technologies
- Real-world AI applications
- Machine learning workflows

**Learning Focus:**

Understanding the development of artificial intelligence, the differences between AI, machine learning, and deep learning, and how machine learning systems are applied to practical problems.

### Module 2: Retrieving and Cleaning Data

**Topics:**

- Retrieving data from CSV and JSON files
- Accessing databases, APIs, and cloud data
- Data cleaning techniques
- Identifying missing values
- Handling missing data
- Detecting outliers
- Evaluating outliers using residuals

**Learning Focus:**

Understanding how to obtain reliable datasets and prepare them for analysis through data cleaning and preprocessing.

### Module 3: Exploratory Data Analysis and Feature Engineering

**Topics:**

- Introduction to exploratory data analysis
- Descriptive statistics
- Data visualization
- Grouping and aggregating data
- Identifying patterns and relationships
- Feature engineering
- Variable transformations
- Categorical feature encoding
- Feature scaling
- Common transformations in Python

**Learning Focus:**

Using statistical summaries and visualizations to understand datasets while preparing meaningful features for machine learning algorithms.

### Module 4: Inferential Statistics and Hypothesis Testing

**Topics:**

- Statistical estimation and inference
- Parametric and non-parametric methods
- Probability distributions
- Frequentist and Bayesian statistics
- Formulating hypotheses
- Hypothesis testing
- Type I and Type II errors
- Statistical significance and p-values
- F-statistics
- Correlation versus causation

**Learning Focus:**

Applying statistical reasoning to evaluate evidence, understand uncertainty, and test research hypotheses.

## 🧪 My Approach to Data Science

I approach machine learning as a scientific process built around questions, evidence, and reproducibility.

### 1. Define the Question

Identify the research problem and determine what information is needed.

### 2. Collect the Data

Retrieve relevant data from reliable sources.

### 3. Prepare the Data

Clean, validate, and transform the dataset.

### 4. Explore the Data

Use descriptive statistics and visualization to investigate patterns and relationships.

### 5. Develop Hypotheses

Formulate testable questions based on observations.

### 6. Apply Appropriate Methods

Use statistical analysis or machine learning algorithms suited to the problem.

### 7. Evaluate Results

Assess performance, assumptions, uncertainty, and limitations.

### 8. Communicate Findings

Present results clearly and document the analytical process.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/rinnyssance/ibm-machine-learning-portfolio.git
```

### Navigate to the Directory

```bash
cd ibm-machine-learning-portfolio
```

### Create a Virtual Environment

```bash
python -m venv .venv
```

### Activate the Environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

### Install Dependencies

Once a `requirements.txt` file has been added:

```bash
pip install -r requirements.txt
```

### Explore the Repository

Navigate to a course directory to review its documentation and any available notebooks, exercises, or completed projects.
